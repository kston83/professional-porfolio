# Security Policy

This is a personal site with no user accounts, no data store, and no
secrets baked into the client bundle — the practical impact of most classes
of vulnerability here is low. Reports are still welcome and will be taken
seriously.

## Reporting a vulnerability

Preferred: use GitHub's [private vulnerability reporting](../../security/advisories/new)
for this repository. This opens a private advisory only visible to the
maintainer, rather than a public issue.

Alternative: email solidsoundschannel@gmail.com with a description of the
issue and reproduction steps.

Please do not open a public issue for a security report.

## Scope

In scope: the application code in this repository.

Out of scope: the hosting platform itself, and vulnerabilities in
third-party dependencies that are already tracked by Dependabot — file
those upstream instead.
