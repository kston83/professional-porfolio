# Portfolio Development Skills

Skills for AI agents working on this portfolio project.

## Available Skills

### content-update
Update portfolio content (experience, projects, about text). Edit `src/data/content.ts`.

### terminal-command
Add or modify interactive terminal commands. Edit `src/scripts/commands.ts`.

### style-update  
Modify visual design. Edit `src/styles/main.css`. Reference the color palette in AGENTS.md.

### deploy
Build and deploy. Run `npm run build` to verify, then push to `main` for auto-deploy.
