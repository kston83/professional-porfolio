# Portfolio Content Drafts

These markdown files contain draft content for the portfolio site. Edit them to match your voice and details, then we'll use them to update `src/data/content.ts` and the terminal commands.

## Files

- `projects.md` — Project descriptions and metadata
- `about.md` — About section, bio, stats
- `experience.md` — Professional timeline (placeholder — fill in your roles)

## Workflow

1. Edit these markdown files with your real content
2. Tell the AI to update the site from these drafts
3. The AI will update `src/data/content.ts`, `src/scripts/commands.ts`, and `index.html` accordingly
